# Исследование скрининга меланомы: ResNeXt50 + CBAM

Проверяемая публичная версия бинарного CV-исследования. Здесь сохранена
основная техническая суть проекта: совместимая с исходным checkpoint
архитектура ResNeXt50-CBAM, разбиение данных без пересечения пациентов или
поражений и парное сравнение моделей. Снимки, веса, секреты и старые notebooks
не публикуются.

> Это исследовательское ПО, а не медицинское изделие. Результат модели не
> является диагнозом и не заменяет осмотр дерматолога, дерматоскопию и
> гистологическое заключение.

## Что удалось подтвердить

- CBAM действительно встроен перед skip-connection в блоках `layer3` и
  `layer4` ResNeXt50.
- Архивный checkpoint строго загружается в публичное определение модели без
  отсутствующих или лишних параметров: 354 тензора, 26 390 707 параметров.
- PyTorch- и ONNX-версии исходной модели дали одинаковый класс на 100 из 100
  контрольных изображений; максимальное расхождение вероятности —
  `2.413988e-06`.
- Утилита разбиения гарантирует, что один `group_id` не окажется в разных
  выборках.

Исторические F1/F2 и ограничения описаны в
[`docs/legacy-results.md`](docs/legacy-results.md). Главное исправление
позиционирования: репозиторий больше не утверждает, что модель доказанно лучше
врача. Для такого вывода архивных данных недостаточно.

## Быстрый старт

```bash
python -m pip install -e '.[dev]'
ruff check .
pytest
```

Для архитектуры PyTorch:

```bash
python -m pip install -e '.[model]'
```

Для формирования разбиения нужен CSV с полями `sample_id`, `group_id`,
`label`, `image_path`:

```bash
melanoma-split manifest.csv --output split.csv --seed 42
```

`group_id` должен обозначать пациента или поражение, а не отдельный снимок.
